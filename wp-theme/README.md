# Kylie Mae WordPress theme

Only this site was converted to WordPress. Other creator sites stay static.

## Install on Hostinger WordPress

1. Download the `wp-theme` folder from this repo.
2. Rename the folder to `kyliemae`.
3. Zip that folder (`kyliemae.zip`).
4. WordPress admin → Appearance → Themes → Add New → Upload Theme → upload the zip → Activate.
5. Settings → Reading → Homepage displays → A static page, or just use the theme index as the front page.
6. Appearance → Customize → **Kylie Mae Landing** → add name, affiliate links, and photos.
7. Pages → Add New → title `DMCA` → Template: **DMCA** → slug `dmca` → Publish.

Settings → Permalinks → Post name → Save.
